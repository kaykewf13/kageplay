Como funciona

O KagePlay tem tres camadas que conversam entre si: a planilha define as regras, o app reproduz, e o Canva (opcional) serve de vitrine.

Arquitetura

🧠 Planilha-mestre — controla animes, episodios, fontes e regras. Decide o que pode ou nao tocar.

⚙️ App / Player — le os arquivos catalog.json, categories.json e playback-policy.json e executa o video quando permitido.

🎨 Canva — vitrine visual com botoes que apontam para o player. Nao executa logica.

Quando um episodio toca dentro do site

O player so reproduz internamente quando as tres condicoes sao verdadeiras:

  • gratuito_autorizado = Sim
  • drm_paywall = Nao
  • publicar = Sim
Se a fonte nao permitir reproducao (DRM, paywall ou iframe bloqueado), o player nao forca nada: ele apenas oferece o botao para abrir a fonte oficial/autorizada.

Fluxo de operacao

  1. Preencher a planilha-mestre (animes + episodios + fontes).
  2. Rodar o script Python que gera catalog.json, categories.json e playlist.m3u.
  3. Publicar os arquivos no GitHub Pages, Netlify ou Vercel.
  4. Apontar os botoes do Canva para app.seudominio.com/player.html?anime=ID&ep=1.
  5. Testar a reproducao no dominio final.

Link inativo

Um link marcado como inativo gera apenas alerta operacional na planilha. Ele nao e a trava principal do player — serve para voce saber o que corrigir.
